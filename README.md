# Document Search Service

REST API для полнотекстового поиска документов.

## Технологии

- Python 3.13
- FastAPI
- PostgreSQL
- Elasticsearch
- Docker

## Возможности

- Поиск документов по тексту
- Сортировка результатов по дате
- Возврат до 20 документов
- Удаление документов из БД и поискового индекса
